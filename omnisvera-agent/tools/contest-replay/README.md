# Contest presentation cut — local audited replay

Start with `node tools/contest-replay/server.mjs` from the Companion directory, then open http://127.0.0.1:18910/.

This standalone static presentation does not integrate with or modify Companion, Core, MCP, model sessions, or databases. The server binds only to loopback and serves exactly four allowlisted presentation files. It does not serve the forensic package. No deployment or Git push was performed.

The presentation is in English for the contest. Play/pause, reset and speed controls use explicitly editorial timing, not measured tool duration. Opening proof or hiding the tab pauses playback. Technical details show the complete server-recorded tool sequence, including repeated reads, errors and limitations. The view is not an independent cryptographic attestation and does not imply prior model identity.

`dist/proof.json` is a curated derivative, generated by `export-proof.mjs` after verifying the frozen SHA256SUMS anchor and each original artifact. It excludes raw prompts/results beyond the single authorized instruction, local file paths, credentials and databases. Original evidence is never written. The exporter requires the local frozen evidence directory as its argument and fails on hash mismatch.

Checks: `node --test tools/contest-replay/replay.test.mjs` and `node --check tools/contest-replay/dist/app.js`.

No external fonts, analytics, packages or network services are needed. Do not deploy the private forensic archive. Any future publication needs its own review and authorization.
